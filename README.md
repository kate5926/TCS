## Detalle de cada tarea

### [Tarea 01 — desarrollo de una web con arquitectura web de n-capas ](tarea01/)
Aplicación web de agenda de contactos organizada en capas: presentación, lógica de negocio y datos.

### [Tarea 02 — Stateful vs Stateless](tarea02/)
2 funciones stateful y 2 funciones stateless en la aplicación desarrollada en la sesión anterior..

### [Tarea 03 — Internacionalización](tarea-03/)
Se agregó vue-i18n para mostrar la aplicación en español o inglés según el parámetro `?lang=` de la URL.

### [Tarea 04 — Idiomas y expresiones regulares](tarea04/)
Menú desplegable para elegir el idioma (español, inglés y portugués) y validación de los formularios con expresiones regulares.

### [Tarea 05 — Componentes distribuidos](tarea05/)
Diagrama de componentes de la aplicación y consumo del servicio externo Open-Meteo (clima) desde el frontend.

### [Tarea 06 — Netlify](tarea06/)
Creación de una cuenta en Netlify y publicación de una aplicación web similar al proyecto del curso.
Sitio publicado: https://quiet-pony-a83cae.netlify.app

---

## Tecnologías utilizadas

- **Frontend:** Vue 3, Vite, vue-router, vue-i18n, axios
- **Backend:** Node.js, Express, Sequelize
- **Base de datos:** PostgreSQL
- **Servicios externos:** Open-Meteo
- **Hosting:** Netlify
